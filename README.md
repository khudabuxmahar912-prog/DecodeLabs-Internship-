# Responsive Developer Portfolio

A single-page responsive portfolio site built with plain HTML, CSS, and JavaScript — no frameworks.

## Description

This project is a mobile-first landing page for a full stack developer. It includes a sticky header with a collapsible mobile nav, a hero section, a responsive project grid, and a contact footer. The layout adapts across three breakpoints (mobile, tablet at 768px, desktop at 1024px) using CSS Grid for page structure and Flexbox for smaller components like the nav bar. Typography scales fluidly with `clamp()` instead of jumping abruptly at each breakpoint.

**Tech stack:** HTML5, CSS3 (Grid, Flexbox, media queries), vanilla JavaScript

## How to Run

No build tools or installs required.

1. Download or clone this repository
2. Open `index.html` directly in any web browser (double-click the file, or right-click → Open With → your browser)
3. Resize the browser window to see the layout adapt across screen sizes
